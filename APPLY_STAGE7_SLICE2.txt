SYLPHY STAGE 7 — COGNITION SLICE 2

Overlay patch: extract at the repository root and allow overwrite. Assumes Cognition Slice 1 is installed.

Implements:
- Brain emits deterministic, bounded CognitionRequestProposal records for new, known sandbox file metadata.
- Runtime constructs requests from current World facts using an explicit metadata allowlist. File contents are not sent to the model.
- Runtime journals requests/results; provider work is asynchronous and uses an exclusive per-model resource lease.
- Brain independently checks source freshness and provenance before retaining cognition output. Model proposals remain non-executable context.
- Public event ingress cannot forge cognition.* events.
- Optional CLI flags enable local Ollama cognition and require --autonomy plus an explicit --sandbox-root.
- Pending request/result events are reconciled from the durable journal after restart.

  python -m pip install -e ".[cognition,dev]"
